# UI/UX BRIEF
Feel: calm, glassy, motivating. Avoid: dark and heavy, cluttered dashboards, fake or demo data. Primary device: phone, one hand, portrait.
Truth: prototype/index.html (all screens and states, including pickers, custom repeat, menus, undo, stats, player). Logo: assets/logo.png.
Screens: Today (greeting, swipeable poster carousel, Today's plan timeline, Coming up), Vault (collection rows), Collection (poster grid), Add/Edit sheet, Date picker, Time picker, Poster menu, Collection menu, Delete-collection sheet, Stats sheet, Player, Settings (Theme, Debug, Delete my data, Export/Import).
Tokens: light bg #F7FCFC to #E4F4F2; ink #082A29; muted #58787A; glass white 55% + blur 26dp + 1dp white edge; accent #14B8A6 to #0A7F86; red #FF3B30 only for "due soon" dot; category gradients Morning #0891B2/#155E75, Motivation #0D9488/#134E4A, Evening #2563EB/#1E3A8A, Study #059669/#064E3B. Font Plus Jakarta Sans. Radius 30dp posters, pill chips/buttons. Floating glass nav (Today, +, Vault).
Component states: default, pressed (scale .95), focus, disabled, loading, error, empty. Forms: inline validation, clear messages. Writing: short, sentence case, plain words.
Accessibility: touch >= 48dp, contrast >= 4.5:1, content descriptions on icon buttons, 200% font scale, reduced motion, TalkBack labels.
